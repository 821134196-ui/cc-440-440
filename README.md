# 霓虹电竞馆 · 电脑包机与外设交接系统

纯 Python 标准库实现(零第三方依赖): `http.server` + `sqlite3` + `unittest`,前端为原生 HTML/CSS/JS 单页应用。

## 启动(单条命令)

```bash
python3 run.py            # 初始化 SQLite + 生成包机/故障/结账演示样例 + 启动服务
# 打开 http://localhost:8000
```

可选参数: `--port 9000` 改端口, `--reset` 清空数据重新生成, `--db 路径` 换数据库文件。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

25 个用例覆盖: **时段竞争**(同机位时段互斥)、**设备唯一**(同外设不同时服务两单, 含数据库唯一索引兜底)、**权限到期**(授权只在包机时段内有效)、**停机补偿**(故障停机从结算快照扣除)、**退款幂等**(同键重放 / 换键拒绝)、**并发开机**(两名前台同时开机仅一人成功)、迟到自动取消、提前结束按实计费、押金扣款关联巡检单、异常扣费冲正。

## 业务规则

| 场景 | 处理 |
|---|---|
| 包机下单 | 锁定机位 + 时段 + 外设套装; 同机位/同外设时段冲突返回 409 |
| 开机 | `BEGIN IMMEDIATE` 事务内校验 `reserved→active`, 并发仅一次成功; 外设逐项出库记录编号与外观; 账号授权激活 |
| 迟到 | 超过 15 分钟宽限未开机 → 自动取消并回收授权 |
| 提前结束 | 按实际使用时长计费 |
| 账号授权 | 仅在 `[valid_from, valid_to]` 内放行; 结束/取消即回收, 超时自动过期 |
| 网络中断/故障 | 故障工单记录停机时长; 未解决的故障计到订单结束; 结算时从计费时长扣除并生成补偿项 |
| 外设损坏/缺失 | 归还时逐项登记; 自动生成结账检查工单(损坏按押金 40% 定损, 缺失全额) |
| 押金扣款 | 结算扣款必须通过 `settlement_deductions` 关联巡检工单(外键强约束) |
| 异常扣费 | 结算确认前可冲正(负数为退给顾客) |
| 退款 | 幂等键唯一 + 每结算单限一笔; 同键重放返回原退款单, 支付适配器只执行一次 |

## 架构

```
run.py                 启动入口(初始化 + 演示数据 + HTTP 服务)
esports/
  db.py                SQLite schema 与 BEGIN IMMEDIATE 事务助手
  services.py          领域服务: 包机/外设交接/授权/故障/巡检/结算
  adapters.py          本地设备适配器(供电/网络/外设回执) + 进程内结算适配器(幂等)
  seed.py              演示数据(用 ManualClock 回放真实业务路径生成)
  api.py               HTTP 路由与静态文件服务
  timeutil.py          时钟抽象(测试注入 ManualClock)
static/                前端: 深炭灰 + 电光青 + 明黄, 触控优先
tests/test_arena.py    25 个业务规则测试
data/esports.db        SQLite 数据(机位与消费快照)
```

## 界面(六个视图)

1. **机位平面图** — 固定网格, 状态着色, 进行中机位显示剩余时间与细进度条, 底部为设备回执流水
2. **包机日历** — 8:00–24:00 时间轴, 按机位分行展示订单条, 顶部新建包机
3. **账号授权** — 授权卡片实时显示 有效/未开始/已过期/已回收
4. **外设套装** — 套装组成与库存编号清单, 单件状态(在库/借出/维修/缺失)
5. **巡检工单** — 故障工单(可标记解决)与巡检工单(可关闭), 支持新建
6. **结账复核** — 待结算订单 → 生成快照 → 确认收款 → 退押金; 赔偿扣款显示关联巡检单号; 附幂等退款演示按钮

外设交接采用编号清单(①②③), 归还时逐项选择 完好/损坏/缺失; 所有操作为单层底部面板, 无多层弹窗, 按钮均 ≥48px 触控目标。
